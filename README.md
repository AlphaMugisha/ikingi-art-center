# Ikingi Art Center

## Overview

A PHP-based website for an art center. The repository includes pages for artworks, programs, artist or visitor information, and a shared set of assets and includes.

## Mission

Create an accessible online space where visitors can discover the art center, explore creative work, and learn about its programs and activities.

## Goals

- Introduce the art center and its purpose.
- Present artworks and creative programs in an organized way.
- Make visitor information easy to find.
- Provide a clear contact and visit pathway.
- Keep shared layout and database logic reusable.

## Technology

- PHP
- HTML, CSS, and JavaScript
- Static assets stored in `assets/` and `images/`

## Project structure

- `index.php` — homepage
- `artwork.php` — artwork page
- `programs.php` — programs information
- `visit.php` — visitor information
- `includes/` — shared PHP components
- `assets/`, `images/` — visual resources

## Local setup

Run with PHP using XAMPP or another compatible web server. Place the repository in the web root and open it through localhost. Configure any database settings in the relevant include files if database functionality is enabled.

## Development priorities

Keep artwork descriptions accurate, optimize image sizes, and ensure the pages are responsive and accessible.
